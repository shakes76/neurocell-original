# Von Neumann Machines
John von Neumann recognised that given UC, it allows the creation of an algorithm that is a Universal Self-replicating Machine (USM), a machine analoguous to the UTM, but capable of constructing any other machine including itself by a single program implemented as a Turing machine. He proposed implementing it on a system of cells using 28 rules that allows maintaining of the program on a 'tape' attached to a machine that contains the instructions of self-replication.

This means that there can be USMs possible and that machines that can self-replicate may result given the correct conditions. It does not tell us however, how such machines can eventuate and why, nor which conditions allow such machines to exist.
