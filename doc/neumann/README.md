# Von Neumann Machines
John von Neumann recognised that the UC and the Universal Turing Machine (UTM) allows the creation of an algorithm that is a capable of reproducing itself and he refered to this as a Universal Constructor, which we will refer to as a Universal von Neumann Machine (UVM), a machine analoguous to the UTM, but capable of constructing any other machine including itself by a single program implemented as a Turing machine. He proposed implementing it on a system of cells using 29 rules that allows maintaining of the program on a 'tape' attached to a machine that contains the instructions of self-replication [1].

This means that there can be UVMs possible and that machines that can self-replicate may result given the correct conditions. It does not tell us however, how such machines can eventuate and why, nor which conditions allow such machines to exist.
