# Turing machines
Alan Turing introduced the concept of Universal Computation (UC) via his Universal Turing Machine (UTM). I have written a separate set of notes on the subject, so here I will recall only the intuitive explanation of UC.

## Universal Computation
Universal computation (UC) allows one to program a machine to complete any algorithm without knowing apriori whether that algorithm will finish (or halt) successfully.

It shows that we can create an algorithm for any task, even one that can simulate any other task(s), the so called Universal Turing Machine (UTM). The UTM or UC howver does not tell us how and what we can program or construct with our computations. It merely tells us, whatever we want is possible or can be found. There is no guarantee that it will halt or it is the optimal algorithm in any sense.
