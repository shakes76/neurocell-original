# Universal Automation
Turing lets us program anything without expectations of being successful (universal computation). Von Neumann showed that we can program self-replication and that it makes use of states and cellular automata (universal replication).

I belive embues a system to become automated, producing machines that consume 'energy' to compute and eventually to reproduce (universal automation).
