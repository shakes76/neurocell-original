## Autoencoders
Can be achieved by ensuring the states of a particular layer is only active neuron states with all signal states turned into quiscent (disabled) states to create bottlenecks. This forces the connections through these bottlenecks to compress information.

The downside is that these aren't naturally created. Methods for natural creation need to be explored. It is unknown whether these bottlenecks will ocurr naturall based on the task and its cost function.
